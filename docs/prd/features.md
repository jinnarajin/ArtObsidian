# 기능 우선순위 (Feature List)

> 작성자: 기획팀 / Claude · 작성일: 2026-08-10 · 버전: v0.1 · 상태: 초안
>
> 근거 문서: `docs/research/painpoints.md`(PP1~6), `docs/research/market.md`(MK). 개발은 이 문서와 `prd.md` 기준으로만 진행.

## P0 — MVP (이것 없이는 제품이 성립하지 않음, 5개)

| # | 기능 | 사용자 가치 | 완료 조건 | 근거 |
|---|---|---|---|---|
| 1 | 마크다운 편집/읽기 (평문 .md 저장) | 어떤 도구로도 열리는 내 파일 — 락인 제로 | 편집/읽기 모드 전환, 저장 결과가 옵시디언에서 그대로 열림 | PP4(락인 불안), MK 3.4 S |
| 2 | `[[위키링크]]` + 자동완성 | 폴더 분류 없이 노트끼리 사후 연결 | `[[` 입력 시 노트명 자동완성, 탭하면 해당 노트로 이동, 옵시디언 링크 문법 호환 | PP5(구조 막막함), MK 3.6 |
| 3 | 노트 목록/폴더 트리 + 검색 | 쌓인 노트를 훑고 텍스트로 되찾기 | 볼트 폴더 구조 표시, 본문·제목 전문 검색으로 노트 도달 | PP2(재발견 실패), PP3 |
| 4 | 이미지 첨부·보기 | 이미지를 텍스트와 동급으로 기록 — 핵심 차별화 | 사진 앱/파일에서 첨부 → 볼트 내 파일로 저장, `![[이미지]]` 옵시디언 임베드 문법으로 노트에 렌더링 | PP1·2·3, MK 3.4 O |
| 5 | 볼트 열기/로컬 저장 | 기존 옵시디언 볼트를 그대로, 구독·계정 없이 사용 | 임의 폴더를 볼트로 열기, 네트워크 없이 전 기능 동작 | PP4, MK 3.2(local-first), 결정 3 |

## P1 — 곧이어 (MVP 검증 후 바로)

| 기능 | 사용자 가치 | 완료 조건 | 근거 |
|---|---|---|---|
| 태그(#) | 폴더 없이 가로지르는 분류·재발견 | 본문 `#태그` 인식, 태그 탭/검색으로 해당 노트 목록 | PP2·3·5 |
| 빠른 검색 (Cmd/Ctrl+K, Spotlight 스타일) | 어디서든 2초 안에 노트 점프 | 단축키로 오버레이 호출, 타이핑 즉시 결과, 엔터로 이동 | PP2 |
| zip 백업/복원 | iCloud 미구독자의 안전망 | 볼트 전체 zip 내보내기(파일 앱·AirDrop) + zip에서 복원 | MK 3.4 T(스토리지 비용 리스크), 결정 4 |
| iCloud Drive 동기화 (옵션) | iPhone 캡처 → iPad/Mac 정리의 멀티기기 흐름 | iCloud Drive 내 볼트 선택 시 기기 간 반영, 끄면 로컬 전용으로 완전 동작 | MK 3.2(iCloud+ 64%), 결정 3 |
| 인박스 빠른 캡처 (iPhone) | 3초 안에 사진+한 줄 던져넣기, 분류 없음 | 앱 진입 1탭 내 새 노트+이미지 첨부, 지정 인박스 폴더에 저장 | PP3(한 폴더 덤핑), 결정 5 |

## P2 — 나중에 (차별화 심화)

| 기능 | 사용자 가치 | 완료 조건 | 근거 |
|---|---|---|---|
| 이미지 태그·메모 | 이미지 자체를 검색으로 되찾기 | 이미지에 태그·캡션 부여(사이드카 .md 등 평문 방식), 검색에 노출 | PP2(원문: "You can't tag them directly") |
| 갤러리 뷰 | 볼트 내 이미지를 레퍼런스 툴처럼 훑기 | 폴더/태그 단위 이미지 그리드 열람 | PP1·6, MK 3.3(Eagle 공백) |
| 그래프 뷰 | 링크 구조를 한눈에, 창발적 구조 확인 | 위키링크=엣지 그래프 표시, 노드 탭으로 이동 | PP5 |
| 유사도 기반 관련 노트 | 잊은 자료의 우연한 재발견 | 노트 하단에 관련 노트 추천 표시 | PP2·6 |
| 프로젝트 컬렉션/무드보드 뷰 | 수집→활용 전환 (작업 시작 시 모아 보기) | 태그·링크 기준으로 이미지+노트를 한 화면에 모아 보기 | PP6 |
