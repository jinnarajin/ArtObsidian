# 로드맵 (순서·의존관계 중심)

> 작성자: 기획팀 / Claude · 작성일: 2026-08-10 · 버전: v0.1 · 상태: 초안
>
> 날짜 약속 없음 — 마일스톤은 순서와 의존관계로만 정의. 각 단계 완료 기준 충족 후 다음으로.

```
M1 → M2 → M3 (= MVP) → M4 → M5 → M6
```

## M1 — 볼트 열기 + 편집 (기반)

- 범위: 볼트(폴더) 열기·로컬 저장(P0-5), 마크다운 편집/읽기(P0-1), 노트 목록/폴더 트리(P0-3 일부)
- 완료 기준: 실제 옵시디언 볼트를 열어 노트를 편집·저장하고, 그 결과가 옵시디언에서 깨짐 없이 열린다.

## M2 — 링크 + 검색 (연결)

- 의존: M1
- 범위: `[[위키링크]]`+자동완성(P0-2), 전문 검색(P0-3 완성)
- 완료 기준: 링크로 노트 간 이동이 되고, 검색으로 임의 노트에 3탭 이내 도달한다.

## M3 — 이미지 (차별화 = MVP 완성)

- 의존: M1 (편집·저장 경로)
- 범위: 이미지 첨부·보기(P0-4) — 사진/파일 첨부, `![[...]]` 렌더링
- 완료 기준: iPhone/iPad/Mac 모두에서 이미지 첨부 노트를 만들고 볼 수 있으며, 옵시디언에서도 동일하게 렌더링된다. **여기까지가 MVP — TestFlight 배포·가설 검증 시작.**

## M4 — 재발견 강화 (P1 전반)

- 의존: M2(검색 인덱스), M3
- 범위: 태그(#), 빠른 검색(Cmd+K), 인박스 빠른 캡처(iPhone)
- 완료 기준: 캡처→태그→검색 재발견의 핵심 시나리오(prd.md §4)가 앱 안에서 끝까지 동작한다.

## M5 — 동기화·안전망 (P1 후반)

- 의존: M1(파일 계층 안정), M3(이미지 파일 처리)
- 범위: iCloud Drive 동기화(옵션), zip 백업/복원
- 완료 기준: iCloud 볼트가 iPhone↔iPad↔Mac에서 반영되고, 동기화 꺼진 로컬 볼트도 zip으로 내보내기·복원된다.

## M6 — QA·출시 준비

- 의존: M4·M5 + MVP 검증 결과(인터뷰·국내 조사 반영)
- 범위: `qa/checklist.md` 합격 기준 전 항목 검증, 페인포인트 검증 결과에 따른 P1 보완, 스토어 심사 준비
- 완료 기준: QA 체크리스트 전 항목 통과 + prd.md §6 미충족 항목(실사용자 검증) 해소.

## 이후 (P2, 별도 계획)

그래프 뷰 → 유사도 관련 노트 → 이미지 태그·갤러리 → 프로젝트 컬렉션. MVP 검증 결과에 따라 순서 재조정.
