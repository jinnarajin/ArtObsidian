## 1. 핀터레스트가 압도적인 이유 — 찾는 게 아니라 흘러들어옴

- "핀터레스트가 압도적. 찾기가 쉬움."
- 관심 있었던 사진들이 알아서 올라오고, 그중 90%가 영감을 주는 것들.
- 사진 하나에서 "타고 타고" 이어지는 연쇄 탐색이 가능 — 시각적 영감을 주는 것이 많다.

**시사점:** 사용자가 원하는 건 검색(내가 찾으러 감)보다 발견(관련된 것이 이어져 나옴)에 가깝다. 위키링크·관련 노트로 "타고 타고" 넘어가는 경험이 이 감각과 맞닿아 있고, P2의 유사도 기반 관련 노트가 이 수요를 직접 겨냥한다.

## 2. 기록은 많이 하지만 흩어져 있다

- 본인이 기록을 엄청 많이 하는 사람인데, 여러 노트(앱)에 널브러져 있음 — 자료, 인쇄물 같은 것들.
- 앱들이 각자 저장하게 만들어서 자료가 흩어지게 됨.
- "의지가 있으면 정리하게 됨. 하는 사람들은 함. (나는) 안 하게 돼."

**시사점:** 페인포인트 조사(PP3 한 폴더 덤핑, 여러 저장소 분산)와 일치. 정리는 의지의 문제라서, 정리를 요구하는 설계는 대부분의 사용자에게 실패한다.

## 3. 정리는 자동으로, 생각 없이 하고 싶다

- "한데다 모아놓고 자동으로 정리해주면 쓸 것 같음."
- "생각이라는 걸 안 하면서 하기 좋(아야 함). 애매할 수 있는 건 고민을 해야 하고" — 분류가 애매한 자료 앞에서 고민하는 순간 정리가 멈춤.
- "그 정도는 할 수 있다. (다만) 정리할 때는 (생각을) 안 하고 싶다."
- 인터뷰어(서진) 아이디어: 틴더처럼 좌우 스와이프로 파일을 정리하는 방식 — 판단을 예/아니오 수준으로 줄이면 생각 없이 정리 가능.

**시사점:** "번거로움 없이 바로 저장, 정리는 나중에"(prd.md §4 가치 3) 방향을 지지하되, 한 단계 더 나간다 — 나중에 하는 정리조차 생각이 필요 없어야 한다. 태그·링크를 수동으로 다는 P1 설계는 이 사용자층에게 부담일 수 있음(반증 근거). 스와이프식 초저마찰 정리, 자동 분류 보조를 P2 후보로 검토할 가치.

## 4. "못 찾는다"와 "안 찾는다"의 경계

- 왜 못 찾느냐고 물으면 — "안 찾는 걸 수도 있음."
- 인쇄물 같은 건 못 찾음. 디지털은 "찾으려면 찾을 수도 있다" — 못 찾음과 안 찾음의 경계에 있음.
- 이유: "너무 많은 데에 놔두니까 하나하나 찾는 것도 쉽지 않다."
- 자료가 "엄청엄청 중요하지는 않아서" 찾는 노력을 들일 만큼의 가치가 없으면 그냥 포기함 → 그래서 위계(중요도 구분) 같은 것도 굳이 안 만듦.

**시사점:** 재발견 실패(PP2)의 실제 메커니즘은 "검색 기능이 없어서"가 아니라 "흩어져 있어서 찾는 비용이 자료의 가치를 넘어서기 때문". 해법은 강력한 검색보다 한 곳에 모이는 것 자체(볼트 하나) + 찾는 비용을 낮추는 것(빠른 검색, 이미지 훑어보기).

## 5. 정리·위계에 대한 회의 — 영감은 흩뿌려져 있어도 된다

- "굳이 정리를 그렇게 해도… 영감이라는 거는 흩뿌려져 있는 거라면 상관없음."
- 폴더 위계나 엄격한 분류에 대한 필요를 느끼지 않음.
- 단, 파일 형식은 묶여 있길 원함 — "PDF는 PDF(끼리)."

**시사점:** 폴더 분류를 강요하지 않는 현재 방향(PP5 대응)을 실사용자가 재확인. 대신 형식별 모아보기(이미지만, PDF만)라는 새로운 요구가 나옴 — P2 갤러리 뷰를 "이미지 갤러리"에서 "형식별 필터 뷰"로 넓히는 근거.

## 6. 기획 반영 정리

| 인터뷰 발견 | 기존 근거와의 관계 | 반영 |
|---|---|---|
| 발견형 탐색("타고 타고") 선호 | PP6(수집→활용)과 연결 | P2 유사도 관련 노트·그래프 뷰의 사용자 근거 강화 |
| 자료가 여러 앱·인쇄물에 분산 | PP3 재확인 | P0 볼트 하나로 모으기 방향 지지 |
| 정리는 자동·무사고(無思考)여야 | PP3·5 재확인 + **새 발견** | 스와이프식 정리·자동 분류 보조를 P2 후보로 추가 검토. 수동 태그(P1)의 부담 리스크 기록 |
| 못 찾음 = 찾는 비용 > 자료 가치 | PP2의 메커니즘 구체화 | 빠른 검색(P1)·훑어보기 뷰의 근거 강화 |
| 위계 불필요, 형식별 묶음은 원함 | PP5 재확인 + **새 발견** | 갤러리 뷰를 형식별 필터 뷰로 확장 검토 |
