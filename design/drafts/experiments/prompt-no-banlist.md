# ArtObsidian 디자인 생성 프롬프트 (공통)

날짜: 2026-08-12 / 버전: v1 / 두 리서치(레퍼런스·slop 가이드)를 합쳐 만든 생성용 프롬프트. 초안 3개는 이 공통 프롬프트 + 각자의 스타일 앵커로 생성.

---

## 공통 프롬프트

ArtObsidian의 메인 화면(노트 읽기 화면) HTML 목업을 만들어라. iPad 가로 화면 기준.

**제품**: 그림 그리는 사람이 미술 자료(레퍼런스 이미지 + 마크다운 노트)를 iPad/맥에서 보며 쓰는 개인 위키. 옵시디언 호환(.md, [[위키링크]]).

**화면 구성**: 좌측 폴더 트리(접을 수 있음), 중앙 노트 본문(제목 + 마크다운 텍스트 + 그림 이미지 2~3장 + [[위키링크]] 몇 개), 우측 또는 하단에 관련 노트. 상단에 빠른 검색(Cmd+K) 진입점.

**원칙**:
- 콘텐츠(그림)가 주인공 — 그림이 뜨는 영역에서 UI는 무채색으로 물러난다 (Procreate 원칙)
- 배경은 순백 금지 — 종이색(크림/웜그레이) 계열. 다크모드라면 보라/네이비가 아닌 먹색(warm black)
- 위계는 그림자·라운딩이 아니라 괘선(hairline rule)과 여백으로
- 실제 미술 노트 내용을 채워라 (예: "인체 크로키", "색채 대비 연구") — lorem ipsum 금지

## 초안별 스타일 앵커

### 초안 1 — 에디토리얼/인쇄물
세리프 헤드라인(한글 세리프 감성), 좁은 본문 폭, 잡지 캡션 스타일 이미지 표기(작품명·연도), 얇은 괘선으로 구획. 레퍼런스: Obsidian Primary 테마, mymind, iA Writer. "나만의 도록(화집)" 느낌.

### 초안 2 — 도구적 미니멀
UI 크롬 최소, 모노크롬, 콘텐츠가 화면의 90%. 사이드바는 텍스트만, 아이콘 최소. 레퍼런스: Procreate, PureRef, Obsidian Minimal 테마. "장식 없음이 개성".

### 초안 3 — 촉각적 아날로그 (절제)
종이 질감 배경(은은한 노이즈), 이미지가 스케치북에 붙인 것 같은 표현(마스킹 테이프·핀은 1~2곳만), 손맛 나는 포인트. 레퍼런스: Muse, Milanote. 스큐어모피즘 키치 금지 — 질감은 소량만.
